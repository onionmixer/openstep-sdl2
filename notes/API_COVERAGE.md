# SDL 2.32.10 public API coverage contract

Status: **delivery contract — only rows marked verified have target evidence**

The final product is a port of SDL 2.32.10, not an OpenStep-only replacement
API. `libSDL2.a` is released only after every ordinary runtime declaration in
the selected upstream public headers is exported and has SDL-compatible
behaviour. The target-specific manifest is generated by
`build/generate-api-manifest-host.sh`, which preprocesses upstream
`src/dynapi/SDL_dynapi_procs.h` with the OpenStep configuration. SDL's GCC 2.7
preprocessor cannot parse its varargs macro records; this static source step
therefore runs on Linux, while final archive `nm` verification runs on the
real target. That upstream file contains 876 macro records before
platform-condition filtering and produces the checked-in 836-symbol OpenStep
baseline. `build/check-openstep-public-header-coverage.sh` separately
preprocesses the complete OpenStep runtime-header set (`SDL.h` plus the
opt-in `SDL_syswm.h` and `SDL_vulkan.h`) and verifies that its 836 ordinary
library declarations exactly match that baseline. It excludes static-inline
helpers/macros, external GL/GLES declarations and upstream `SDL_test*`
support; `SDL_main` is explicitly recognized as an application-owned entry
point, not a `libSDL2.a` export.

When OpenStep does not expose a class of hardware, the corresponding SDL2
enumeration/query APIs must still link and use the standard zero-device or
unsupported-result behaviour. They may not disappear from the archive. A
failure result is acceptable only where SDL2 itself defines that result for an
unavailable platform capability; a placeholder success or a private substitute
is not acceptable.

## Required proof for final `libSDL2.a`

1. Regenerate `SDL2.32.10.OPENSTEP_API_MANIFEST.txt` from the exact
   `release-2.32.10` dynapi runtime declaration source, then run
   `build/check-final-api-manifest.csh` on the target against final
   `libSDL2.a`. Any missing one of its 836 symbols fails the release gate.
   `check-openstep-public-header-coverage.sh` must also pass: it validates
   the matching public declarations and documents why `SDL_main` is not an
   archive export. A final-archive-only i486 consumer also includes that
   complete runtime header set and passes its headless `SDL_syswm` and Vulkan
   standard-fallback paths on the real target.
2. Build an upstream-compatible API exercise per group above. A symbol is not
   considered ported merely because a stub satisfies the linker.
3. Run headless tests by Telnet and AppKit/SoundKit/GL tests on the OpenStep
   console. Retain target logs with source revision and compiler flags.
4. Build at least one unmodified SDL2 application from each relevant class
   (software window/event, audio, threaded timer and OpenGL) against final
   `libSDL2.a`. Passing evidence now covers unmodified 2D, audio, timer,
   thread and fixed-function OpenGL consumers; the GL consumer is the official
   SDL 2.0.0 `testgl2` source retained byte-for-byte because it declares a
   Mesa-3.4.2-compatible GL 1.1 surface. The current SDL 2.32 variant remains
   a documented correct capability-check rejection for this historical GL 1.2
   implementation.
5. Do not ship the private `SDL_OpenStepQuitCore` prototype helper or its
   `libSDL2-core-prototype.a` archive. They exist solely to validate compiler
   gates before complete `src/SDL.c` integration replaces them.

diagnostic archive to `libSDL2.a`. On this historical toolchain the archive
table of contents records its pathname; without this last indexing step a
symbol-complete copied archive can still be rejected by the static linker as
out of date.

The host-side public-header audit was then added to make the declaration side
of that proof reproducible. With OpenStep preprocessor conditions it finds
exactly 836 ordinary runtime declarations across `SDL.h`, `SDL_syswm.h` and
`SDL_vulkan.h`; the only additional SDL-prefixed declaration is the
application-owned `SDL_main`. A separate real i486 final-archive consumer
included those headers, exercised their C89-visible helper declarations and
passed both the standard SYSWM unknown result and the no-Vulkan fallback.

## Diagnostic archive workflow

`build/build-sdl2-openstep-diagnostic-archive.csh` recompiles every currently
validated source group. `assemble-sdl2-openstep-diagnostic-archive.csh` can
then archive those exact objects with unique short member names, avoiding the
OPENSTEP `ar` 15-character member-name truncation. On the current target,
`ld -r` closure linking is the reliable integration proof: legacy
`ar`/`ranlib` emits symbol-less-member diagnostics and target archive-wide
`nm` intermittently reports `no name list`; the reporter therefore extracts
and examines each short member. The current target diagnostic result is
`836/836` public declarations present. This is still never evidence for a
release: only `check-final-api-manifest.csh` may approve a final archive named
`libSDL2.a` after a reliable final export audit.
