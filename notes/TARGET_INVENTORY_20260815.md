# OPENSTEP 4.2 target inventory — 2026-08-15

Status: **Phase 0 plus selected Phase 1 core evidence; not a complete SDL2 build result**

The target was initially reached through `tools/nxrun.sh` (the existing Telnet
fallback) on 2026-08-15.  GCD was subsequently restored: `gcdsd` must be
started from the logged-in OPENSTEP `Terminal.app` session, after which
`tools/nx.sh --ping` and GCD-based source/test execution work.  A daemon
started from Telnet is still valid for non-GUI work, but is outside that
console's AppKit/DPS session.
